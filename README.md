# Facebook-Sentiment-Analysis-using-NLP-Machine-Learning
This project focuses on analyzing user sentiments from Facebook posts/comments using Natural Language Processing (NLP) and Machine Learning techniques.The goal is to classify text into sentiment categories such as Positive, Negative, and Neutral, helping businesses understand user opinions and improve decision-making.

Features
Text preprocessing and cleaning (removal of noise, stopwords, punctuation)
Sentiment classification using ML models
Feature extraction using TF-IDF / Count Vectorizer
Model evaluation using standard metrics
Easy-to-understand and scalable pipeline


Tech Stack
Programming Language: Python
Libraries:
Pandas, NumPy
Scikit-learn
NLTK / SpaCy
Matplotlib, Seaborn
Tools: Jupyter Notebook / VS Code


Dataset
The dataset contains Facebook posts/comments with corresponding sentiment labels.
Data includes textual content that is preprocessed before feeding into models.


Project Workflow
1. Data Collection
Collected dataset containing Facebook comments/posts.


3. Data Preprocessing
Lowercasing text
Removing stopwords and punctuation
Tokenization
Lemmatization/Stemming


5. Feature Engineering
Converted text into numerical form using:
TF-IDF Vectorizer
Bag of Words


7. Model Building
Implemented multiple Machine Learning models:
Logistic Regression
Naive Bayes
Random Forest
